# DeskSignal ownership and asset audit

- Original MIT copyright and license retained verbatim; README and website link to Danrui Meng / lolPing.
- Riot-owned signal/emote images, animation and audio remain separately attributed, outside the MIT code license.
- App, installer, menu-bar icons and settings logo are original DeskSignal artwork generated by `tools/make_icon.py`.
- App ID, settings folder, package metadata and updater endpoints point to the independent DeskSignal edition.
- User-facing branding and release workflows use DeskSignal. Lowercase upstream room/crypto identifiers remain intentionally compatible.
- Homepage has no external font loader, analytics script or pixel. Fonts use the local system stack.
- Homepage text explains that the scene is a virtual desktop rendered by the real application overlay.
- Homepage includes a local MP4, poster, manual audio controls and a relative download link. The playable file is copied by the normal Vite asset pipeline.
- Settings browser preview is marked as simulated IPC; it does not read global input or contact room relays.
- No installer Release was published and no system permissions were changed. Global input/network behavior still needs real desktop testing.

## 0.5.2 input update

The input helper now supports keyboard-down opening and keyboard-up selection. This is a functional extension, not just a branding fork. Permission scope is unchanged: global input uses the existing macOS Accessibility grant. The old drag mode and all pre-existing input tests remain available.
