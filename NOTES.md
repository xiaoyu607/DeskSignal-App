# DeskSignal implementation notes

Upstream: https://github.com/darrenprx/lolPing
Baseline: f24a51e5a11c2b31dab72d89a571cc4025ad3c98 (main; includes v0.5.1)
Mode: desktop fork with an independent brand and settings/website design.
License: MIT source code; Riot-owned graphics/audio are excluded. LICENSE retained verbatim.

The C++ input helper extends upstream with a Hold state: key down opens the wheel at the cursor, free mouse movement selects a slice, and key up releases it. The overlay animations/sounds, wheel picking, display coordinate conversion and room crypto/transports remain based on upstream code. Lowercase room protocol namespaces are retained for compatibility. Branding, app ID, local settings folder and update source are independent.

The homepage video is generated by tools/capture-video.mjs from the same overlay renderer used by the desktop application. Its capture scene is an authored simulated desktop, not a recording of the user's personal screen. Ping and emote sounds are mixed at their actual cue timestamps. The settings browser preview uses an explicit mock IPC adapter and does not grant system input access or contact relays.

Validation results are recorded in CLONE_REPORT.md. Desktop global input, permissions, exclusive fullscreen and multi-device room networking require real interactive system testing. No installed-app equivalence is claimed from browser previews alone.

## Keyboard hold mode (0.5.2)

`holdToOpen` defaults to true, including migration of old settings that omit the field. Switching it off preserves the original drag state machine. Keyboard events now carry current cursor coordinates on macOS and Windows. Escape, right-click, ordinary clicks, foreign keys/chords, suspension, disabling and configuration changes cancel without sending. Native legacy clients that omit the field retain their existing drag semantics. Mouse side-button gestures remain unchanged.
